# 用語・略語

## プロジェクトとアプリ

プロジェクト名は「日本自動車連盟（JAF）新ロードサービスシステム構築」。システム名は「JAF RSシステム」。受付、指令、車両・基地業務等のアプリに分かれる。業務上の「受付」「救援依頼」「指令」等を、一般的な受注・配送システムの用語に置き換えずに読む。

以下はアプリケーションコードと名称の対応。SDK はここでは「車両動態管理」であり、開発用 SDK ではない。

| 略号 | アプリ名 | 略号 | アプリ名 |
| --- | --- | --- | --- |
| UKT | 受付アプリ | SRI | 指令アプリ |
| JSR | 自動指令アプリ | SDK | 車両動態管理アプリ |
| SHS | スマホ指令アプリ | KIT | 基地業務アプリ |
| SYG | 車両業務アプリ | JMY | 乗務予定アプリ |
| SYR | 車載連携（対車載・基地）アプリ | SYN | 車載ナビアプリ |
| MST | マスターメンテアプリ | KIN | 勤怠管理アプリ |
| GRJ | 外部連携（対JAF内システム）アプリ | GRG | 外部連携（対外業務連携）アプリ |
| LNC | ランチャーアプリ | RSZ | RS実績入力アプリ |
| SDR | 損保データ連携アプリ | SYO | 承認アプリ |
| RSJ | BIツール | | |

アプリを指す文脈では「受付／受付アプリ／UKT」「指令／指令アプリ／SRI」「ランチャー／ランチャーアプリ／LNC」はそれぞれ同じアプリを表す。他のアプリも「アプリ」を省いた名称を使う場合がある。「車載連携アプリ」は「車載連携（対車載・基地）アプリ」（SYR）に対応する。括弧の全角・半角は区別しないが、GRJ の「対JAF内システム」と GRG の「対外業務連携」は区別する。

Launcher（ランチャー、LNC／`JAFRSPO`）はアプリの共通起動口。受付アプリの通常起動は、このランチャーから行う。

これらは名称対応であり、全アプリの配備・利用可能性を示すものではない。「受付G」「指令G」「車載G」はプロジェクトの担当グループであり、アプリ利用者の権限・ロールではない。

## 機能・処理・用例の識別子

| 種類 | 例 | 意味 |
| --- | --- | --- |
| アプリコード | `UKT` | 受付アプリを識別するコード |
| クライアントのプロジェクト名 | `JAFRSAO` | 受付クライアントの名称。単一画面の ID ではない |
| 機能 ID | `JAFRSAO00010` | 受付アプリ起動・終了機能。機能 ID があっても同名の操作画面が存在するとは限らない |
| 画面 ID | `JAFRSAO01001` | 受電画面。起動・終了機能から表示される画面の一つ |
| 処理・イベント ID | `JAFRSAO00010E001` | 機能に属する個別処理。この例は初期処理。`E`・`P` 等の接尾部も保持して識別する |
| テストケース ID | `JAFRSAO00010E001_0001` | 処理に対する個別の試験項目。同じ処理に複数のケースを持てる |

この形式の処理 ID を機能単位で対応付ける場合は先頭 12 文字を使う。ただし、結果・障害記録では元の処理 ID・テストケース ID を保持し、別処理や別ケースを統合しない。形式が異なる識別子へ一律に適用しない。これらの識別子、DB のサブシステム ID（受付は `1`）、自動化プラットフォームの実行 ID は別物。

## 受付業務・連携の用語

以下は受付アプリでの用法。共通の語であっても、他アプリの取得方法・操作条件が同じとは限らない。

| 用語 | 意味・適用範囲 |
| --- | --- |
| 受電 | 電話の着信・応答を扱う機能。受電画面は `JAFRSAO01001` |
| 救援依頼入力 | 救援依頼の受付内容を入力する画面 `JAFRSAO02001` |
| 受付番号 / `uketsuke_no` | 受付案件の識別子。テスト実行 ID・利用者 ID ではない |
| 受付ロック | 利用者・端末・サブシステムに関係する受付案件の編集状態。Windows デスクトップの予約とは別 |
| 端末番号 / `term_no` | 登録端末の識別子。端末 IP と同じ値とは限らず、ログイン時に装置情報から取得する |
| RSCC | ユーザーの担当拠点に関係するコード。`rsccCode` として取得し、本部・支部・端末番号と区別する |
| CTI / StationLink | 電話制御連携。受付アプリは CTI 制御アプリへ使用開始・終了を要求し、着信等の通知を受ける |
| 名前付きパイプ | 指令→受付、CTI→受付等のアプリ間通信。画面をクリックすることと通信要求の検証は別 |
| 研修フラグ | 研修用画面を表示する起動条件。研修操作の権限を自動付与するものではない |
| 広域フラグ | 起動時に受け取る `koikiLoginFlg`。管理者権限や全機能の利用許可という意味ではない |
| 点滅支部設定 | 端末・アプリに対して保持する対象支部の設定。レコード登録と画面上の点滅確認は別の観測 |
