# 仕様書の表記・改訂規則

JAF のテスト仕様書に共通する読取・対象判定の規則。

## 対象範囲と改訂

- 灰色背景のセル・行と削除線の記述は対象外とし、RV・テスト実行・結果判定から除外する。
- システム既定の背景色は、廃止を示す灰色に含めない。
- 部分的な灰色背景・削除線は該当箇所だけを除外し、残る有効な記述を対象とする。
- 対象外部分の空欄や旧記述は仕様不備・未実行失敗として数えない。
- 黄色等の強調はブックの凡例・改版履歴に従う。置換文は有効な記述を採用する。

## 共通の読み方

- 表紙・改版履歴・概要から対象機能、版、前提条件を確認する。
- テスト内容、期待結果、前提・入力パターン、別シートの確認資料を対応付ける。
- 結合セルは左上の値と結合範囲を使って読む。ケース ID とブック・シート・位置を保持する。
- DB・ログ等の確認資料欄は検証方法、既存の結果欄・再テスト欄は過去の記録として読む。

## Markdown 変換後

- 本文と取得したセル書式を合わせて読み、部分削除線は該当文字列に適用する。
- 条件付き書式の `NOT_EVALUATED` は未評価を表す。
- 除外箇所は原文に残し、RV の適用範囲付記に記録する。実行・判定はその範囲を引き継ぐ。
