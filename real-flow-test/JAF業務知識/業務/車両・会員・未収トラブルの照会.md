# 車両・会員・未収トラブルの照会

## 車両選択

「車名検索」「メーカー」は車両選択画面 `JAFRSAO07004` を開く。

- 車両分類は自動車、二輪／原付、その他を区別する。メーカー・通称名の表示名だけで分類を判断せず、選択レコードの分類コードと対応付ける。
- 選択確定後はメーカーのコード・名称、通称名のコード・名称、備考と車両分類を親画面へ反映する。車両情報のマスターと親画面の候補一覧も必要。
- 「検索条件を入力した」「結果行を選択した」「選択ボタンで確定した」は別の状態。親画面への反映は選択確定後に確認する。
- 再表示時のメーカー・検索語・車両分類の保持は、親から渡す初期値と子画面の初期化条件に依存する。現行の試験期待との未確定差分を、業務上の保持不要というルールに置換しない。
- ナンバー地名はナンバー地名選択画面 `JAFRSAO07002` を使う。地名表示と登録地コードを対応させ、自動車等の分類条件も保持する。

## 会員照会

「会員照会」は会員情報照会画面 `JAFRSAO08001` を開く。

照会には聞取り会員番号、氏名カナ／漢字、住所、電話、会員区分・状態・有効期限、車両ナンバー等を渡す。カナ氏名がない場合に親画面のお客様名を渡す経路がある。

戻りデータがある場合に、会員情報や関連する車両情報を親画面へ反映する。聞取り会員番号の入力だけで、会員が照会・確定された状態と判断しない。キャンセルと対象会員の選択確定を区別する。

会員区分、状態、有効期限、番号、氏名、住所、電話の期待値は同じ会員に関連付ける。照会画面の登録地表示と、受付に保存する登録地コードの変換も区別する。

## トラブル・未収照会

「トラブル・未収」は未収・トラブル情報照会画面 `JAFRSAO09001` を開く。

親画面からは現在の受付番号、受付完了日、会員番号、氏名・電話、指令番号を渡す。受付完了日時が未設定なら受付日付も未指定。指令番号の未設定を表す値は、照会時に空文字へ変換する経路がある。

初期検索の終了日は、受付完了日を渡した場合はその日、未指定なら取得したシステム日付。開始日はその基準日から `max(mishuSearchRange, troubleSearchRange)` 年を引いた日になる。「3」は月数・日数ではなく、この初期計算では年数として読む。画面のクリア後は別の初期化条件があるため、初期表示と同一視しない。

| 確認対象 | 判定の要点 |
| --- | --- |
| 検索条件 | 会員番号、氏名、電話、指令番号、期間等の受渡しと画面値を照合する |
| 0件 | 正常に照会して該当なしなのか、通信・取得の異常なのかを区別する |
| 複数件・表示上限 | 取得件数と表示件数を区別する。表示上限の設定と超過の案内も関係する |
| 金額 | 数値と表示書式を区別する。未収金額・残高には桁区切りと金額単位を付ける処理がある |
| 詳細 | 一覧の選択レコードと、詳細照会に使う伝票番号・トラブル番号を対応付ける |

外部照会、検索結果、詳細結果は別のデータ。データセットに検索結果だけを置いて、外部呼出しの前提や詳細結果も準備済みと扱わない。固定の期間期待と基準日が合わない場合はRVで確認し、実行日を理由に期待値を黙って変えない。
