# 指令・地図・予約・安心コール

## 指令情報の関連

指令管理コードは指令を識別する値であり、受付番号や号車番号とは別。現在の受付案件に関連付いた指令から、指令員、基地、乗務員、号車、動態、後方警戒車等の表示に必要な情報を取得する。

対話履歴の指令取得は現在の受付番号を条件にする。受付と指令の準備が別の受付番号では、指令管理コードだけ一致していても当該案件の表示前提を満たさない。

本指令、未指令、取消等はボタン活性や子画面遷移の条件に関係する。指令データの有無だけで状態を判断せず、ケースが対象とする区分・状態と関連マスターを合わせる。

## 地図の用途

出動場所、運び先、現在地の表示には受付用地図画面 `JAFRSAO04001` を使う。用途に応じて受付番号・枝番、住所・座標、指令状態等を渡す。

| 操作 | 渡す情報・確認対象 |
| --- | --- |
| 地図（出動場所） | 受付案件の出動場所。住所、緯度経度、道路・支部等の関連情報 |
| 地図（運び先） | 運び先の住所・座標等。出動場所の表示と区別する |
| 現在地 | 受付・指令に関連する車両等の表示条件。受付番号・枝番と指令状態も関係する |

現在地は未指令と判定した場合、`JAFRSAIC00023` を表示して地図を開かない。受付番号だけを用意して「現在地」の正常遷移を前提にしない。

入力開始済みの現在地呼出しでは、受付枝番から1を引いた値を渡す経路がある。現在表示中の枝番を、そのまま全地図照会の枝番へ流用しない。

地図の表示と、選択した場所の親画面への反映は別の結果。住所・名称・座標・道路区分を対象項目ごとに照合する。モーダル性に未確定差分があるケースは、実行中に期待を置換しない。

## 高専道画面

安全確認の「高専道(安全確認)」と、道路・指令等の情報を表示する「高専道」は異なる操作。後者は高専道画面 `JAFRSAO02003` を開く。

受付番号・枝番、受付開始時刻、出動場所の住所・座標・道路・上下線・キロポスト、待合せ場所、指令員、乗務員・車両・基地等を渡す。親の参照状態を子画面の読み取り専用指定へ対応させる。表示名と準備した指令・道路の関連を確認する。

## 予約問合せ

遷移前に必要項目・場所等のチェックを行い、入力中の経路では必要な受付履歴更新が失敗すると遷移しない。予約問合せ画面 `JAFRSAO06002` へ受付番号・枝番と親の参照状態を渡す。

子画面で確定した予約日・時刻は、変換結果とともに受付の予約日時へ反映する。予約積載車フラグ、予約料金、強制予約・自動指令なし予約等は別の項目・条件を持つ。日付と時間だけを用意して、すべての固定期待が成立するとは判断しない。

現行の予約問合せの名称だけのデータセットは保留のままとする。空き状況、料金、指令との条件を知識追加だけで作成しない。

## 安心コール

受付番号・枝番から取得した安心コール実施状況と指令管理コードを使う。確認済み状態では「安心コール済」を活性・青背景・白文字とする経路があり、それ以外は「安心コール未」を非活性・黄背景・黒文字とする。

安心コール実施確認画面 `JAFRSAO02011` へは対象の指令管理コードを渡す。同画面が既に開いている場合は閉じて開き直す。別案件の指令を準備して、現在の受付の安心コール確認済み状態と扱わない。画面を開く権限と、照会／入力モードに応じた追加の権限も区別する。
