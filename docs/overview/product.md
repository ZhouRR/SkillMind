# 利用ガイド

Skillmind は Skill 原文を実行根拠とし、入力選択・資源接続・タスク実行・外部変更・結果監査をプロジェクト単位で管理する。現在の利用可能範囲と検証待ち事項は [Roadmap](../planning/roadmap.md#現在の実行状態) を参照する。

## Skill から結果まで

1. 組織スキル庫で Skill を取り込み、解析されたタスク・必須入力・資源宣言を確認して公開する。
2. プロジェクトで該当バージョンを有効化し、「資源と接続」で資格情報とアクセス範囲を設定する。
3. タスクと文書範囲を選び、事前確認（プリフライト）を経て起動する。反復実行はタスクカードから定期実行を設定する。
4. ワークスペースで進行中タスクと待機中項目を確認し、質問への回答や変更提案の承認を行う。
5. 「完了とレポート」でタスクごとの最新終態サマリを確認し、実行履歴の詳細で結果・添付・証拠・評価を閲覧する。

公開・プロジェクト有効化・資源準備は個別に検査される。モデルの推測を入力とみなしたり文書範囲を自動拡張したりしない。新規 Skill は最小限の入力/資源宣言と凍結原文で実行される。

## 画面の役割

| 画面 | 主な用途 |
| --- | --- |
| 概要 | 待機項目、最近の実行、プロジェクト入口 |
| 組織スキル庫 | 名称・識別子・版・状態による絞込、取込・解釈・公開・有効化・版整理 |
| タスク | 名称・識別子・定期実行状態での検索、タスク起動とスケジュール設定 |
| ワークスペース | 待機中・進行中・タスク別の最新レポート |
| 実行履歴 | ページング閲覧、所要時間、単回詳細、ごみ箱管理 |
| プロジェクト文書 | アップロード、フォルダ選択、改名、移動、プレビュー、ダウンロード、ごみ箱 |
| 資源と接続 | 資格情報、許可範囲、PostgreSQL・文書庫・Git・MCP 接続 |
| プロジェクトとアカウント | メンバー、アーカイブ、アカウント安全、管理者管理 |

ADMIN は組織スキル・プロジェクト・資源を管理し、一般ユーザーは許可されたプロジェクトで操作する。外部連携用の API Key は [API ガイド](../development/api-usage.md) を参照する。解析完了後に下書き未作成のまま同一タブを更新・遷移した場合は、再解析せず元要求の結果を復元できる。

## 自動承認と結果の見方

起動時の自動承認は当該実行に対する明示的同意であり、DB・文書・Git・MCP の同意範囲をサーバー側で個別に検証する（権限・競合・回読検査は省略しない）。チェックを外した場合は都度承認となる。

プラットフォームの実行完了（`SUCCEEDED`）、結果の完全性、業務上の `PASS`/`FAIL` は別の事実である。レポートはモデルが提示した結論と引用を表示し、自動で合格を推測しない。

## 旧データの整理

実行履歴と文書はごみ箱への移動・復元・完全削除に対応する（削除前にプレビューで関連成果と参照ブロックを確認する；原入力と共有参照は保護され、外部 DB や Git 記録は削除されない）。削除監査がプロジェクトに紐付くため、履歴一覧が空でも物理削除できない場合はアーカイブを維持するか、アーカイブ済みプロジェクトの完全削除を使う。

構成は[アーキテクチャと用語](architecture.md)、障害対応は [Runbook](../operations/runbook.md) を参照する。
