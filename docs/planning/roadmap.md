**整体完成度约 55%：核心链路已成形，可靠性和真实环境验收尚未完成。**

评估基准：2026-09-10。100% 指当前 R01–R13 全范围的实现、契约、消费者、回归和真实交付均完成。百分比是工程粗估，误差约 ±10 个百分点，不是测试覆盖率、业务准确率或剩余工期比例；整体不是各项简单平均。

- 当前策略：先完成真实只读业务闭环；Task Flow、生成界面、外部写入和调度扩展后置。

## 首版目标与推进顺序

**一个真实 Skill + 一种只读资源，完成导入、解释、发布、手动运行、结果溯源和人工评价，并能处理失败、取消和重启。**

1. **确认真实用例（R06 / R12）**：选择高价值 Skill 和可人工核对的案例，明确规则保真、证据、结果可用性及耗时/费用的验收标准；输入与评价答案隔离。
2. **补齐运行底线（R01 / R05 / R06 / R07 / R02）**：收口权限、冻结输入、异步原请求、导入存储、可靠停止与主执行预算。R12 持续反馈，不要求各项先全部达到 100%。
3. **完成首版交付（R10 / R11 / R13）**：完善必要页面，在获准环境验证部署、真实执行和恢复，逐项检查本期需求后进入小范围试用。

必要页面限定为登录/账户安全、项目与成员基础、Skill 导入发布、一种资源配置、任务选择、Workspace（答复、取消、结果与评价）及历史回看。文档管理仅在选择文档资源时纳入。

### 后置能力的边界

- R03 / R04 / R08 / R09 的扩展、子 Agent 和高级组合暂不开放；后置不代表删除设计要求或视为已完成。
- 当前普通 Run 与 Effect 共用 dispatch 开关，子 Agent 已被装配，Schedule tick 已注册。须落实 API、能力和 Worker 执行门禁，并检查已有队列及恢复入口；隐藏菜单、缺少写凭据或 `dispatch=false` 均不是完整关闭证明。
- Tasks/Resources 页面仍依赖调度/预授权读取；关闭后端能力时同步拆开读取依赖，不使核心页面一起失败。
- 限定只读资源不能自动解决 Skill 导入存储风险。停止发布不等于远端 PUT 停止，业务取消不等于模型停止；未知调用、写入和费用不得盲目重试、退额或视为已结清，处置遵循所属设计。

## 首版验收与停止条件

- **业务有用**：真实 Skill 使用指定版本和真实只读来源完成任务，规则、证据和结果通过事先约定的人工检查；结构有效或 fixture 成功不能代替业务质量。
- **边界可信**：越权/撤权、输入篡改、重复提交、断线、取消、限额和未知恢复有证据；非首版能力在服务端被拒绝。
- **可以交付**：目标镜像、配置、迁移、健康检查、重启、备份与恢复完成实际验证；首版所用 Secret 可恢复且未泄露。
- **证据分层**：mock/fake、真实 DB、浏览器、模型、外部资源和部署分别说明已验与未验范围。skip、旧测试次数、文档构建和局部通过不能关闭其他缺口。

以上条件满足即可进入小范围试用，不追求全项目某个百分比。首版验收不关闭后置任务，也不代替全项目 R13 审计。
