## 当前执行状态

**整体完成度约 55%：核心链路已成形，可靠性和真实环境验收尚未完成。**

评估基准：2026-09-12。100% 指当前 R01–R13 全范围的实现、契约、消费者、回归和真实交付均完成。百分比是工程粗估，误差约 ±10 个百分点，不是测试覆盖率、业务准确率或剩余工期比例；整体不是各项简单平均。

- 已有基础：身份与项目、资源冻结、Skill 导入发布、手动 Run、标准结果和人工评价。
- 主要欠账：异步授权、统一预算接线、可信停止、异常恢复及真实业务/部署验收。
- 当前策略：完整验收 rv-reviewer，补齐其 Excel 转换和受控 MinIO/PostgreSQL 写入；Task Flow、生成界面、无关外部写入和调度扩展后置。

## 首版目标与推进顺序

**完整执行 rv-reviewer：先登记 PostgreSQL RUNNING → Excel 选择/取得 → Worker MarkItDown 转换 → MinIO 原文备份 → RV → PostgreSQL 评价记录及所需 MinIO 结果保存 → 关闭执行记录；完成 Skill 导入、解释、发布、手动 Run、结果溯源和人工评价，并处理失败、取消和重启。**

1. **确认真实用例（R06 / R12）**：以 rv-reviewer 原文为验收基线，不删去前置 DB 登记、备份/结果保存及异常对账步骤；确定 Excel 案例、MinIO/PostgreSQL/MarkItDown 接入和人工验收标准，输入与评价答案隔离。
2. **补齐运行底线（R01 / R05 / R06 / R07 / R02）**：收口权限、冻结输入、异步原请求、导入存储、可靠停止、主执行预算及 RV 所需受控写入。R12 持续反馈，不要求各项先全部达到 100%。
3. **完成首版交付（R10 / R11 / R13）**：完善必要页面，在获准环境验证部署、真实执行和恢复，逐项检查本期需求后进入小范围试用。

必要页面限定为登录/账户安全、项目与成员基础、Skill 导入发布、本用例资源配置、任务选择、Workspace（答复、取消、结果与评价）及历史回看。文档管理仅在选择文档资源时纳入。

### 后置能力的边界

- R03 / R04 / R09、子 Agent、高级组合及 R08 无关写入后置；R08 中本用例的 PostgreSQL/MinIO 写入纳入首版。
- 默认关闭 `SKILLMIND_DEFERRED_FEATURES_ENABLED`、`SKILLMIND_DATABASE_WRITES_ENABLED` 和 `SKILLMIND_DOCUMENT_WRITES_ENABLED`：分别控制既有外部写入/调度/子 Agent、PostgreSQL INSERT/UPDATE、文档库 Artifact CREATE；均与普通 Run 的 dispatch 分开。限制覆盖 API、能力目录、实际 Worker job 和恢复入口，已有队列也不能绕过；隐藏菜单或缺少凭据不是关闭证明。读取历史、取消 Run、停用调度/预授权继续保留。已有快照不删权限来冒充首版 Run，含禁用能力的执行须明确拒绝。
- RV 的数据库和文档写入按独立开关配置；不能为 RV 一次性放开调度、子 Agent 或所有 Provider。新增写入须有精确 capability/operation 门禁和批准/幂等/回读协议，装配并验收后才单独开放，见[受控写入](../design/repository-effects.md#首版所需的存储和数据库写入)。
- Tasks/Resources 按会话返回的部署状态省略调度/预授权读取与后置操作入口；手动 Run、只读资源配置和已有调度历史保持可用。
- 限定只读资源不能自动解决 Skill 导入存储风险。停止发布不等于远端 PUT 停止，业务取消不等于模型停止；未知调用、写入和费用不得盲目重试、退额或视为已结清，处置遵循所属设计。

## 首版验收与停止条件

- **业务有用**：rv-reviewer 使用指定版本和真实 Excel 来源完成原文全部处理与记录，规则、证据和结果通过事先约定的人工检查；结构有效或 fixture 成功不能代替业务质量。
- **边界可信**：越权/撤权、输入篡改、重复提交、断线、取消、限额和未知恢复有证据；非首版能力在服务端被拒绝。
- **可以交付**：目标镜像、配置、迁移、健康检查、重启、备份与恢复完成实际验证；首版所用 Secret 可恢复且未泄露。
- **证据分层**：mock/fake、真实 DB、浏览器、模型、外部资源和部署分别说明已验与未验范围。skip、旧测试次数、文档构建和局部通过不能关闭其他缺口。

以上条件满足即可进入小范围试用，不追求全项目某个百分比。首版验收不关闭后置任务，也不代替全项目 R13 审计。
