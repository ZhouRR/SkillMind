# Skillmind 实施计划

本页是当前进度与优先顺序的唯一正本；详细规则见[设计索引](../design/README.md)，代码接续见[变更指南](../development/change-guide.md)。维护方式见[文档约定](../development/documentation.md#维护进度报告)。

## 当前执行状态

**全量目标完成度约 65%；当前小范围首版约 80%。核心业务链路已可运行，正式测试计划发布、Runner 接入和异常恢复尚未全部闭环。**

评估基准：2026-09-14。全量 100% 包含 R01–R13 的实现、契约、消费者、回归和实际交付；首版仅包含下文约定的使用范围。两者均为工程粗估，误差约 ±10 个百分点，不是测试覆盖率、业务准确率或剩余工期比例；整体按业务重要度判断，不取各项简单平均。

当前按用户要求冻结整体业务复验，先完成可用性与 Git 写入完善。RV 原文现采用单任务 oneshot，审批和必要确认后在同一任务继续，不再拆成审查与恢复两项任务。既往人工核对记录保留其局限：预设 5 类缺陷检出 4 类，曾纠正列名/保存内容/转换版记录；后续应使用独立答案做无辅助复验，不把流程打通等同于质量达标。

## 首版目标与推进顺序

**首版以单次启动完成 RV 全部处理、可信保存与可读报告为基线，增加测试用例/计划生成和经批准的 Git 提交能力。流程已可运行，质量与恢复继续单独验收。**

1. **当前完善（R08 / R10 / R13）**：完成 Git 写入、原结果核对和资源页面入口；整理最新文档与契约，保留冻结的业务记录。
2. **恢复业务验收后（R06 / R12）**：处理计划开始/结束时间约束，配置正式 IR 发布位置与 Runner/MCP；用同一版本、固定输入和独立预期验证单任务完成，不靠人工补写闭环。
3. **试用收口（R01 / R05 / R07 / R02 / R11）**：重点验证撤权、取消、重复提交、预算、断线与重启恢复。正常路径可用后仍须保全未知效果，不把新建 Run 当恢复。

必要页面限定为登录/账户安全、项目与成员基础、Skill 导入发布、本用例资源配置、任务选择、Workspace（答复、取消、结果与评价）及历史回看。文档管理仅在选择文档资源时纳入。

### 后置能力的边界

- R03 / R04、子 Agent、高级组合及 R08 中 SVN/Redmine 写入与 PR 自动创建后置；PostgreSQL/MinIO、Git 提交和基础定期执行纳入首版。
- 后置功能、PostgreSQL、文档保存及 Git 分别由独立开关控制，默认关闭；启用一项不开放其余能力。配置与升级方式只维护在[发布指南](../operations/deployment.md#迁移前置与执行)。Run dispatch 与权限/批准仍独立检查；旧队列不绕过当前开关，读取历史和停止操作保留。
- 新 Run 的默认勾选自动批准包含 Git；未勾选、旧 Run 和 SVN 保持原审批规则；原连接的只读范围不会随部署自动扩张。完整批准、精确 scope、原身份和回读见[受控写入](../design/repository-effects.md)。
- Tasks/Resources 按会话返回的部署状态按独立调度开关显示定期执行入口，省略未开放的预授权读取与后置操作入口；手动 Run、只读资源配置和已有调度历史保持可用。
- 限定只读资源不能自动解决 Skill 导入存储风险。停止发布不等于远端 PUT 停止，业务取消不等于模型停止；未知调用、写入和费用不得盲目重试、退额或视为已结清，处置遵循所属设计。

## 首版验收与停止条件

- **业务有用**：rv-reviewer 使用指定版本和真实 Excel 来源完成原文全部处理与记录，规则、证据和结果通过事先约定的人工检查；结构有效或 fixture 成功不能代替业务质量。
- **边界可信**：越权/撤权、输入篡改、重复提交、断线、取消、限额和未知恢复有证据；非首版能力在服务端被拒绝。
- **可以交付**：目标镜像、配置、迁移、健康检查、重启、备份与恢复完成实际验证；首版所用 Secret 可恢复且未泄露。
- **证据分层**：mock/fake、真实 DB、浏览器、模型、外部资源和部署分别说明已验与未验范围。skip、旧测试次数、文档构建和局部通过不能关闭其他缺口。

以上条件满足即可进入小范围试用，不追求全项目某个百分比。首版验收不关闭后置任务，也不代替全项目 R13 审计。
