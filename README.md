- [利用・保守ガイド](docs/README.md)：使用、開発、配備と障害対応。
- [開発案内](SKM/README.md)：コード入口、環境構築と検証。
- [現在の進捗](docs/planning/roadmap.md)：実装・検証状況と実利用に基づく改善方針。

正式コードは `SKM/`、ガイドは `docs/` に置く。詳細な契約・処理はコードとテストを参照する。
